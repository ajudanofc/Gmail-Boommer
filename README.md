## 📌 Description
**Gmail Boommer** is a lightweight email testing tool built for **educational purposes and penetration testing simulations**.

It helps security researchers and developers:

- Test email delivery reliability
- Stress-test SMTP servers
- Evaluate spam filters
- Perform controlled mail flood simulations in lab environments

⚠️ **Disclaimer:**  
This tool is intended strictly for **legal testing and research only**.  
Any misuse, spamming, or illegal activity is **not the responsibility of the author**.

## 📥 Installation

### 📱 Termux
```bash
apt update && apt upgrade
pkg install git python
git clone https://github.com/ajudanofc/Gmail-Boommer
cd Gmail-Boommer
python3 spam.py
```

---

### 🐧 Linux (Debian / Ubuntu / Kali)
```bash
sudo apt update && sudo apt upgrade
sudo apt install git python3
git clone https://github.com/ajudanofc/Gmail-Boommer
cd Gmail-Boommer
python3 spam.py
```

## ▶️ Usage
```bash
python3 spam.py
```

Then follow the prompts:
- Target email
- Message content
- Amount
- Delay (optional)
